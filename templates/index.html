Welcome to Security Demo Application

This is an educational web application that demonstrates common web vulnerabilities and their detection/prevention.

Available Vulnerabilities for Demonstration:

1. SQL Injection

Go to Login page and try entering: ' OR '1'='1 in the username field.

Detection: The system will detect and log this attack attempt.

2. Cross-Site Scripting (XSS)

Go to Comments page and try: <script>alert('XSS')</script>

Detection: Malicious scripts will be detected and blocked.

3. Command Injection

Go to Network Tools and try: 127.0.0.1 & whoami

Detection: Command injection attempts will be detected.

4. Cross-Site Request Forgery (CSRF)

The transfer page lacks CSRF protection - demonstrates how attacks work.

Prevention: Use Flask-WTF forms with CSRF tokens.
